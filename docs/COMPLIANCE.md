# 合规清单 Compliance Checklist

> 本清单用于上线前自查，不替代律师意见。正式上线前请由执业律师审阅。

## 面向中国大陆用户

- [ ] **ICP 备案**：网站使用境内服务器并面向公众提供服务，需办理备案；若涉及经营性服务，需办理 ICP 许可证
- [ ] **公安联网备案**
- [ ] **跟帖评论管理**（《互联网跟帖评论服务管理规定》）：用户身份认证（后台实名、前台自愿）、评论审核机制、举报处理、违规处置
- [ ] **论坛社区管理**（《互联网论坛社区服务管理规定》）：板块管理、信息安全管理制度
- [ ] **个人信息保护**（《个人信息保护法》）：隐私政策、单独同意（实名认证属敏感个人信息）、用户删除账号与数据的通道、最小必要收集
- [ ] **网络信息内容生态**：内容审核、违法信息处置与留存记录
- [ ] **AI 相关**：若使用大模型对公众生成回答或推荐内容，需评估是否适用《生成式人工智能服务管理暂行办法》等规定
- [ ] **法律服务边界**：平台不收费撮合律师业务，不以平台名义提供个案法律意见

## 面向欧盟用户

- [ ] GDPR：合法性基础、数据主体权利、数据跨境传输机制
- [ ] 《数字服务法》(DSA)：通知与处理机制、透明度要求（按平台规模适用）

## 面向美国用户

- [ ] 各州对"未经授权执业"(UPL) 的限制：只提供法律信息，不针对个案给出建议
- [ ] COPPA：不面向 13 岁以下儿童

## 通用

- [ ] 所有页面显示免责声明
- [ ] 求助帖发布前强制提示脱敏
- [ ] 律师认证须核验执业证，并定期复核
- [ ] 审核日志留存
